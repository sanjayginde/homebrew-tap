# sanjayginde/homebrew-tap

Homebrew formulae and casks for my projects.

| Name | Install | Description |
|------|---------|-------------|
| [claude-code-manager](https://github.com/sanjayginde/claude-code-manager) (`ccm`) | `brew install sanjayginde/tap/claude-code-manager` | Terminal UI for browsing, managing, and resuming Claude Code sessions |
| [Glimpse](https://github.com/sanjayginde/glimpse) | `brew install --cask sanjayginde/tap/glimpse` | Menu bar monthly calendar |

`Formula/claude-code-manager.rb` and `Casks/glimpse.rb` are updated automatically by each
project's release workflow.
